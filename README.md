# 📟 Nokia Lyrics Player (NokiNotes)

A retro-styled **Nokia-inspired lyrics player** that plays **Drake’s song “Nokia”** with real-time synced lyrics. Relive the nostalgia of old-school Nokia phones with a pixel-art LCD interface built with **HTML, CSS, and JavaScript**.  

---

## 📖 Description

**NokiNotes** displays the lyrics of Drake’s “Nokia” as the song plays, offering a simple, interactive, and visually engaging music experience. Designed with nostalgia in mind, it combines retro pixel styling with modern web functionality.  

**Key highlights:**  
- Real-time lyrics synchronized with Drake’s “Nokia”  
- Classic Nokia-style pixel LCD interface  
- Progress bar to visualize song playback  

---

## 🛠️ Technologies Used

- **HTML5** – Structure and audio playback  
- **CSS3** – Retro pixel-style styling  
- **JavaScript** – Lyrics synchronization and UI interactivity
